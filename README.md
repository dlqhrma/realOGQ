# AI 설비보전기능사 CBT Coach

AI 기반 맞춤형 학습을 제공하는 설비보전기능사 필기시험 CBT 학습 웹 서비스

---

# 프로젝트 소개

AI 설비보전기능사 CBT Coach는 설비보전기능사 필기시험 준비자를 위한 AI 기반 맞춤형 학습 웹 서비스입니다.

기존 CBT 학습 방식은 대부분 기출문제 풀이 중심으로 구성되어 있어 사용자가 틀린 문제의 원인을 이해하거나 부족한 개념을 다시 학습하는 과정에 어려움이 있었습니다.

또한 반복적인 기출문제 풀이만으로는 새로운 문제 상황에 대한 대응력과 개념 이해도를 높이는 데 한계가 있었습니다.

본 서비스는 이러한 문제를 해결하기 위해 AI를 활용하여 문제 생성, 상세 해설, 오답 관리, 학습 분석 기능을 제공하는 개념 이해 중심의 CBT 학습 플랫폼을 개발했습니다.

사용자는 원하는 조건에 맞는 문제를 생성하고, 실제 시험과 유사한 CBT 환경에서 학습하며, AI 해설과 학습 분석을 통해 자신의 부족한 부분을 파악할 수 있습니다.

현재 버전은 설비보전기능사 필기시험 대비를 위한 MVP(Minimum Viable Product) 형태로 개발되었으며, 향후 다양한 국가기술자격 필기시험으로 확장 가능한 구조를 목표로 개발했습니다.

---

# 개발 배경

설비보전기능사 필기시험을 준비하는 과정에서 기존 CBT 서비스의 한계를 경험했습니다.

기존 CBT 서비스는 많은 기출문제를 제공한다는 장점이 있지만 다음과 같은 문제점이 있었습니다.

- 문제를 맞혔는지 확인하는 수준에 머무름
- 틀린 문제의 원인 분석 부족
- 관련 개념을 다시 찾아보는 과정 필요
- 반복되는 기출문제로 새로운 문제 유형 대비 어려움
- 개인별 취약 영역 분석 부족

특히 자격증 필기시험은 단순 암기보다 개념 이해와 문제 상황 판단 능력이 중요하지만, 기존 학습 방식에서는 이러한 부분을 충분히 지원하지 못했습니다.

이를 해결하기 위해 AI를 활용한 맞춤형 학습 서비스를 개발했습니다.

AI 기반 문제 생성 기능을 통해 다양한 문제를 경험하고,
AI 해설과 오답노트를 통해 틀린 이유를 이해하며,
학습 분석 기능을 통해 개인별 취약 영역을 확인할 수 있도록 설계했습니다.

# 주요 기능

## 1. AI CBT 시험

실제 설비보전기능사 필기시험과 유사한 CBT 환경을 제공합니다.

### 기능

- 시험 문제 수 선택
  - 20문제
  - 40문제
  - 60문제

- 객관식 4지선다 문제 제공
- 시험 종료 후 자동 채점
- 점수 및 정답률 확인
- 단원별 성취도 분석
- 틀린 문제 자동 저장


CBT 시험에서는 시험 진행 중 정답과 해설을 제공하지 않아 실제 시험과 유사한 환경을 제공합니다.

시험 종료 후 저장된 결과 데이터는 오답노트와 학습 분석 기능에서 활용됩니다.

---

## 2. AI 문제 생성

사용자가 원하는 조건에 맞는 설비보전기능사 학습 문제를 생성합니다.

### 선택 조건

### 단원

- 기계구동장치
- 공유압장치
- 전기전자장치
- 용접 및 안전관리


### 난이도

- 쉬움
- 보통
- 어려움


### 문제 수

사용자가 원하는 개수만큼 문제 생성 가능


생성되는 문제는 설비보전기능사 시험 범위를 기반으로 구성되며,
실제 기출문제를 복사하지 않고 학습 목적에 맞는 새로운 문제를 생성합니다.

---

## 3. AI 해설

사용자가 문제를 이해하고 오답 원인을 파악할 수 있도록 상세 해설을 제공합니다.

### 제공 내용

- 정답 근거 설명
- 오답 선택지 분석
- 핵심 개념 설명
- 시험 포인트
- 암기 팁


단순히 정답만 제공하는 방식이 아니라,

"왜 이 답이 정답인지"

"왜 다른 선택지는 틀렸는지"

를 이해할 수 있도록 구성했습니다.

---

## 4. 오답노트

시험 결과에서 틀린 문제를 자동으로 저장하여 반복 학습을 지원합니다.

### 기능

- 틀린 문제 자동 저장
- 날짜별 오답 관리
- 문제 재확인
- AI 해설 연결
- 유사문제 생성


사용자는 자신이 자주 틀리는 문제와 개념을 확인하여 효율적으로 복습할 수 있습니다.

---

## 5. 학습 분석

CBT 시험 결과 데이터를 기반으로 학습 상태를 분석합니다.

### 제공 내용

- 전체 정답률
- 단원별 정답률
- 취약 단원 분석
- 반복 오답 개념 분석
- 추천 학습 방향


단순한 시험 결과 제공이 아니라 사용자가 다음 학습 방향을 결정할 수 있도록 지원합니다.

# AI 정확도 관리 방식

생성형 AI를 활용한 학습 서비스에서는 잘못된 정보 생성(Hallucination)을 방지하는 것이 중요합니다.

특히 자격증 시험 학습 서비스는 잘못된 개념이나 해설이 제공될 경우 학습자에게 직접적인 영향을 줄 수 있기 때문에 AI 응답 품질 관리 구조를 설계했습니다.


## 1. Knowledge 기반 생성 구조

설비보전기능사 시험 범위를 기반으로 직접 구축한 Knowledge 데이터를 활용합니다.

AI는 문제 생성과 개념 설명 과정에서 Knowledge 데이터를 최우선 기준으로 사용합니다.


구조:

사용자 입력

↓

System Prompt 규칙 적용

↓

Knowledge 데이터 기반 AI 생성

↓

서비스 출력


이를 통해 일반적인 AI 답변이 아닌 설비보전기능사 학습 목적에 맞는 답변을 생성하도록 구성했습니다.


---

## 2. 기능별 Prompt 분리 설계

하나의 AI에게 모든 기능을 요청하지 않고,
기능별 역할을 분리하여 Prompt를 설계했습니다.


총 9개의 Prompt를 구성했습니다.


### System Prompt

전체 AI 서비스의 기본 규칙 관리

관리 내용:

- 시험 범위 기준
- 문제 생성 규칙
- 단원 관리
- 난이도 기준
- 출력 형식
- 데이터 일관성


---

### Problem Prompt

AI 문제 생성 기능 담당

설계 기준:

- 선택 단원 기반 문제 생성
- 난이도별 문제 조절
- 4지선다 구성
- 정답 1개 유지
- 중복 문제 방지


---

### CBT Prompt

실제 시험 환경 생성 담당

설계 기준:

- 20 / 40 / 60문제 선택
- 4개 상위 단원 균형 출제
- 실제 시험 난이도 반영
- 정답 위치 균형 배치
- 시험 중 해설 제한


---

### Answer Prompt

AI 해설 기능 담당

설계 기준:

- 정답 근거 설명
- 오답 이유 분석
- 보기별 분석
- 핵심 개념 설명
- 시험 포인트 제공


---

### Similar Prompt

유사문제 생성 담당

설계 기준:

- 틀린 문제만 대상
- 동일 핵심 개념 유지
- 새로운 상황 구성
- 단순 숫자 변경 방지
- 동일 난이도 유지


---

### Concept Prompt

개념 설명 담당

설계 기준:

- 개념 정의
- 역할
- 작동 원리
- 특징
- 시험 포인트


중심으로 초보 학습자가 이해하기 쉽게 설명하도록 구성했습니다.


---

### Wrong Note Prompt

오답노트 관리 담당

설계 기준:

- 틀린 문제만 저장
- 풀이 날짜 관리
- 반복 오답 관리
- AI 해설 및 유사문제 연동


---

### Analysis Prompt

학습 분석 담당

설계 기준:

- CBT 결과 데이터 기반 분석
- 단원별 정답률 분석
- 취약 개념 분석
- 학습 방향 추천


---

### Output Format Prompt

AI 출력 형식 관리

설계 기준:

- 기능별 출력 구조 통일
- 데이터 저장 안정성 확보
- 화면 출력 오류 방지

# 기술 스택

## Backend

- **Python**

  AI API 연동, 데이터 처리 및 서비스의 핵심 기능을 구현하기 위해 사용했습니다.

  문제 생성, CBT 시험 진행, 오답노트 관리, 학습 기록 저장, 학습 분석 등 주요 비즈니스 로직을 Python 기반으로 구현했습니다.

- **Streamlit**

  Python 기반 웹 애플리케이션 프레임워크로 사용했습니다.

  별도의 프론트엔드 개발 없이 AI 학습 서비스를 빠르게 구현할 수 있도록 활용했으며, 웹 화면과 백엔드 기능을 연동하여 다음 기능을 구현했습니다.

  - AI 문제 생성
  - CBT 시험
  - AI 해설
  - 오답노트
  - 학습 분석

---

## AI

- **Google Gemini API**

  Google AI Studio에서 발급받은 Gemini API를 연동하여 AI 기능을 구현했습니다.

  사용자가 선택한 단원과 난이도에 맞는 문제 생성, 정답 및 해설 작성, 개념 설명, 유사 문제 생성 등의 기능을 제공합니다.

- **google-genai SDK**

  Python 환경에서 Gemini API를 사용할 수 있도록 지원하는 공식 SDK입니다.

  프롬프트를 API로 전달하고 AI 응답을 받아 웹 서비스 화면에 출력하는 기능을 구현했습니다.

- **Prompt Engineering**

  AI가 학습 목적에 맞는 문제와 해설을 생성하도록 프롬프트를 설계했습니다.

  기능별 요구사항을 반영하여 문제 생성, 해설 작성, 개념 설명, 학습 분석 등의 응답 품질을 향상시켰습니다.

- **System Prompt 기반 AI 응답 제어**

  AI가 설비보전기능사 CBT 학습 도우미 역할을 수행하도록 System Prompt를 설계했습니다.

  문제 생성, CBT 시험, AI 해설, 개념 설명, 오답노트, 학습 분석 등 기능별 응답 규칙을 정의하여 출력 형식과 난이도를 일관성 있게 유지하도록 구성했습니다.

- **Structured Output 설계**

  AI 응답을 일정한 형식으로 반환하도록 출력 구조를 설계했습니다.

  문제, 선택지, 정답, 해설 등을 구조화된 형태로 생성하여 서비스 화면에서 안정적으로 활용할 수 있도록 구현했습니다.

# 보충 작업


### 로그인 기능 수정 과정

**문제점**
기존에는 로그인 기능이 제대로 연결되지 않아 사용자의 아이디와 비밀번호를 이용해 계정을 확인하고, 로그인 상태를 유지하는 과정이 부족했다.

**수정한 코드**
로그인 정보를 데이터베이스에서 확인하고, 로그인에 성공하면 `st.session_state`에 사용자 정보를 저장하도록 수정하였다.

if login_success:
    st.session_state.user_id = user_id
    st.session_state.logged_in = True
    st.switch_page("pages/home.py")


또한 `app.py`에서 로그인 여부에 따라 접근할 수 있는 페이지를 구분하도록 구성하였다.

if "user_id" in st.session_state:
    pg = st.navigation([
        home,
        problem,
        cbt,
        note,
        analysis,
        result,
        review,
    ])
else:
    pg = st.navigation([
        login,
        signup,
    ])

pg.run()


**수정 결과**
로그인에 성공하면 사용자 정보를 세션에 저장하고 홈 화면으로 이동하도록 개선하였다. 또한 로그인한 사용자만 CBT, 오답노트, 학습분석 등의 기능을 이용할 수 있도록 페이지 접근 구조를 구성하였다.
