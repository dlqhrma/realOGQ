## 프로젝트 제목

# AI 설비보전기능사 CBT Coach

AI 기반 맞춤형 학습을 제공하는 설비보전기능사 필기시험 CBT 학습 웹 서비스


## 프로젝트 소개

AI 설비보전기능사 CBT Coach는 설비보전기능사 필기시험 준비자를 위한 AI 기반 맞춤형 학습 웹 서비스입니다.

기존 CBT 학습 방식은 기출문제 풀이 중심으로 구성되어 있어 사용자가 틀린 이유를 이해하거나 부족한 개념을 보완하는 데 어려움이 있었습니다.

본 서비스는 Gemini AI를 활용하여 학습자가 원하는 조건의 문제 생성, AI 해설, 오답노트, 학습 분석 기능을 제공하여 단순 암기가 아닌 개념 이해 중심의 학습 환경을 제공합니다.

사용자의 학습 데이터를 기반으로 취약 단원을 분석하고 개인 맞춤형 학습 방향을 제시하는 것을 목표로 합니다.


## 개발 배경

설비보전기능사 필기시험을 준비하면서 기존 CBT 학습 방식의 한계를 경험했습니다.

기존 CBT 문제는 과거 기출문제 중심으로 구성되어 있어 최신 시험 경향과 차이가 있었으며, 오답에 대한 정확한 원인 분석과 관련 개념 학습이 어렵다는 문제가 있었습니다.

또한 틀린 문제를 다시 학습하거나 부족한 개념을 찾아보는 과정에서 많은 시간이 필요했습니다.

이러한 문제를 해결하기 위해 AI를 활용한 맞춤형 CBT 학습 서비스를 개발하게 되었습니다.

AI 기반 문제 생성과 해설, 학습 분석 기능을 통해 학습자가 자신의 부족한 부분을 파악하고 효율적으로 시험을 준비할 수 있도록 지원합니다.

## 주요 기능

## 1. AI CBT 시험

- 실제 설비보전기능사 필기시험과 유사한 40문제 CBT 환경 제공
- 시험 종료 후 점수 및 결과 분석 제공
- 단원별 정답률 확인
- 오답 문제 자동 저장


## 2. AI 문제 생성

사용자가 원하는 조건에 맞는 문제 생성

- 단원 선택
  - 베어링
  - 용접
  - 윤활
  - 유압
  - 공압
  - 기계요소

- 난이도 선택
  - 쉬움
  - 보통
  - 어려움

- 문제 개수 선택

생성된 문제는 설비보전기능사 출제 범위를 기반으로 구성


## 3. AI 해설

틀린 문제의 원인을 이해할 수 있도록 상세 해설 제공

- 정답 근거 설명
- 오답 선택지 분석
- 핵심 개념 설명
- 시험 포인트 제공
- 암기 팁 제공


## 4. 오답노트

- 틀린 문제 자동 저장
- 날짜별 오답 관리
- 문제 재풀이 기능
- 유사 문제 생성


## 5. 학습 분석

학습 결과 데이터를 기반으로

- 전체 정답률 분석
- 단원별 취약점 분석
- 추천 학습 방향 제공
