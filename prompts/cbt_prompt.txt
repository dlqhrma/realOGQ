# CBT Prompt

## 현재 모드
CBT 시험

## 목적
실제 설비보전기능사 CBT 시험과 유사한 환경으로 시험 문제를 생성한다.

## 시험 규칙

1. 시험은 항상 40문제로 구성한다.
2. 문제는 다음 4개 상위 단원을 기준으로 출제한다.

- 기계구동장치
- 공유압장치
- 전기전자장치
- 용접 및 안전관리

각 단원 내부의 세부 개념(베어링, 윤활, 유압, 공압, 기계요소 등)을 활용하여 문제를 생성한다.
세부 개념 목록은 대표적인 출제 영역이며,
CBT 문제 출제 범위를 제한하지 않는다.

AI는 각 상위 단원의 설비보전기능사 시험 범위 내 관련 개념을 활용하여 문제를 구성한다.

3. 특정 단원에 문제가 과도하게 집중되지 않도록 하며,
실제 설비보전기능사 출제 경향을 고려하여 단원별 출제 비율을 조절한다.

모든 단원이 시험에 포함되도록 구성하며,
각 단원의 문제 수가 반드시 동일할 필요는 없지만 특정 단원이 전체 문제 대부분을 차지하지 않도록 한다.

4. 실제 설비보전기능사 CBT 수준과 유사한 난이도를 반영한다.
5. CBT 시험은 사용자가 난이도를 선택하지 않는다.
실제 설비보전기능사 필기시험의 난이도와 출제 경향을 반영하여 다양한 난이도의 문제를 구성한다.
6. 동일한 문제나 동일한 핵심 개념이 과도하게 반복되지 않도록 하며, 다양한 단원과 상황을 반영하여 출제한다.
7. 시험 진행 중에는 정답과 해설을 출력하지 않는다.
8. 채점과 결과 분석을 위해 문제, 보기, 사용자 선택 답안, 정답, 해설, 단원, 난이도 및 핵심 개념 정보를 서비스 내부 저장 데이터로 관리한다.
9. 시험 종료 후 저장된 CBT 결과 데이터는 오답노트 저장, AI 해설, 유사문제 생성 및 학습 분석 기능에서 활용한다.
10. system_prompt.txt의 모든 규칙을 따른다.
11. output_format.txt의 출력 형식을 따른다.
12. 문제 출제 순서는 무작위로 구성하며, 단원과 난이도가 한쪽으로 치우치지 않도록 한다. 또한 정답 번호가 특정 위치에 반복되지 않도록 실제 CBT 시험과 유사한 환경을 제공한다.

13. CBT 40문제 구성 시 동일 핵심 개념 출제 비율을 제한한다.

하나의 세부 개념이 전체 문제 대부분을 차지하지 않도록 제한한다.

가능한 경우 동일 세부 개념 출제는 2~3문제 수준으로 유지하되,
해당 개념이 설비보전기능사 시험에서 중요도가 높은 경우에는 조정할 수 있다.

14. CBT 문제 구성 시 단순 암기 문제만 반복하지 않는다.

전체 문제는 다음 유형이 균형 있게 포함되도록 한다.

- 정의 확인 문제
- 원리 이해 문제
- 특징 비교 문제
- 설비 적용 문제
- 고장 원인 분석 문제
- 정비 및 유지보수 방법 판단 문제
- 계산 문제

계산 문제는 설비보전기능사 시험 범위 내에서 출제하며,
전체 문제에서 과도한 비율을 차지하지 않도록 한다.

15. 동일한 개념을 출제하는 경우에도
문제 상황과 판단 기준을 다르게 구성한다.

16. CBT 시험 문제의 모든 보기는 문제의 핵심 개념과 관련된 선택지로 구성한다.

오답 보기는:
- 같은 단원 내 관련 개념
- 실제 시험에서 혼동 가능한 개념
- 판단이 필요한 선택지

로 구성한다.

관계없는 용어, 다른 분야의 부품명, 의미 없는 선택지는 사용하지 않는다.

17. CBT 시험 문제의 난이도는 실제 설비보전기능사 필기시험의 출제 경향과 난이도 분포를 반영하여 구성한다.

사용자가 난이도를 선택하지 않으며,
기본 개념 확인 문제, 원리 이해 문제, 특징 비교 문제, 실제 설비 적용 및 고장 판단 문제를 실제 시험과 유사한 비율로 포함한다.

단순 암기 문제만 반복하지 않으며,
시험에서 요구하는 개념 이해와 현장 적용 능력을 평가할 수 있도록 구성한다.
