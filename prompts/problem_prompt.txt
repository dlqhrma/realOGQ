# Problem Prompt

## 현재 모드
문제 생성

## 목적
사용자가 선택한 조건에 맞는 설비보전기능사 CBT 객관식 문제를 생성한다.

## 사용자 입력

단원 :
난이도 :
문제 수 :

## 생성 규칙

사용자 입력값(단원, 난이도, 문제 수)을 기준으로 아래 규칙을 적용하여 문제를 생성한다.

1. system_prompt.txt의 모든 규칙을 따른다.
2. output_format.txt의 출력 형식을 따른다.
3. 사용자가 선택한 단원에서만 문제를 생성한다.
4. 사용자가 선택한 난이도를 반영한다.
5. 사용자가 요청한 문제 수만큼 생성한다.
6. 객관식(4지선다) 문제만 생성한다.
7. 생성하는 모든 문제에는 다음 정보를 함께 생성한다.

- 문제
- 보기
- 정답
- 해설
- 단원
- 핵심 개념
- 난이도

생성된 문제 데이터는 AI 해설, 오답노트 저장, 유사문제 생성 기능에서 활용할 수 있도록 동일한 형식을 유지한다.
생성된 문제 데이터의 정답, 해설, 핵심 개념 정보는 문제 생성 후 변경하지 않으며, 이후 기능에서도 동일한 데이터를 기준으로 활용한다.

8. 정답과 해설 데이터는 내부적으로 생성하되, 문제 생성 화면에서는 문제와 보기만 표시한다. 사용자가 답안을 제출한 후 정답과 해설을 제공한다.
9. 동일한 요청에서 생성되는 문제는 서로 다른 개념, 상황 또는 표현을 사용하며, 동일하거나 유사한 문제가 반복되지 않도록 생성한다.
10. 요청한 문제 수를 충족하되, 동일한 문제를 반복하거나 보기만 변경한 문제는 생성하지 않는다.
11. 생성된 모든 문제는 문제 번호 순서대로 출력하며, 각 문제는 output_format.txt의 형식을 동일하게 따른다.
12. 문제는 설비보전기능사 필기시험에서 요구하는 기본 개념, 원리 이해 및 적용 능력을 평가할 수 있도록 생성한다.
13. 보기는 정답 1개와 오답 3개로 구성하며, 오답은 실제 시험에서 혼동할 수 있는 수준으로 자연스럽게 작성한다.
14. 계산식, 단위, 수치가 포함되는 문제는 설비보전기능사 시험 범위 내의 공식과 기준을 사용하며, 불필요하거나 근거 없는 수치를 사용하지 않는다.
15. 동일한 단원에서 여러 문제를 생성할 경우,
같은 핵심 개념만 반복하지 않는다.

가능한 경우 다음 유형을 균형 있게 활용한다.

- 개념 이해 문제
- 구조 및 구성 문제
- 작동 원리 문제
- 특징 비교 문제
- 고장 원인 문제
- 정비 방법 문제
- 계산 문제
- 실제 현장 적용 문제


16. 같은 개념을 다시 출제해야 하는 경우,
기존 문제와 다른 학습 목표를 가지도록 구성한다.

예:
"릴리프 밸브의 역할은?"
→ 기본 개념 확인

다음 문제:
"유압 회로 압력이 상승할 때 발생하는 현상과 관련 밸브는?"
→ 상황 판단 문제


17. 생성되는 문제끼리는 정답뿐만 아니라 문제 의도와 풀이 과정도 반복되지 않도록 한다.
