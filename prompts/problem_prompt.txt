# Problem Prompt

## 현재 모드
문제 생성

## 목적
사용자가 선택한 조건에 맞는 설비보전기능사 CBT 객관식 문제를 생성한다.

## 사용자 입력

단원 :
난이도 :
문제 수 :

## 생성 규칙

사용자 입력값(단원, 난이도, 문제 수)을 기준으로 아래 규칙을 적용하여 문제를 생성한다.

1. system_prompt.txt의 모든 규칙을 따른다.
2. output_format.txt의 출력 형식을 따른다.
3. 사용자가 선택한 상위 단원 범위 내에서만 문제를 생성한다.

선택된 상위 단원의 세부 개념 목록은 대표적인 출제 영역이며,
문제 생성을 위한 제한 목록이 아니다.

세부 개념 목록에 포함되지 않은 내용이라도,
선택된 상위 단원의 설비보전기능사 시험 범위에 포함되는 관련 개념이라면 문제 생성에 활용할 수 있다.

세부 개념 목록은 출제 가능한 모든 내용을 의미하지 않으며,
대표적인 학습 영역을 표시하기 위한 기준이다.

AI는 해당 목록 외에도 선택된 상위 단원의 설비보전기능사 필기시험 범위에 포함되는 관련 개념을 활용할 수 있다.

단, 다른 상위 단원에서 독립적으로 관리되는 핵심 개념은 문제 생성에 사용하지 않는다.


예:

사용자가 선택한 단원:
기계구동장치

활용 가능:
- 베어링
- 윤활
- 축
- 축이음
- 기어
- 벨트
- 체인
- 나사
- 키
- 핀
- 스프링
- 기타 기계구동장치 관련 내용


활용 불가:

- 공유압장치 관련 내용
  (유압, 공압, 밸브, 실린더 등)

- 전기전자장치 관련 내용
  (전기 회로, 센서, 모터, PLC 등)

- 용접 및 안전관리 관련 내용
  (용접, 산업 안전, 보호구 등)


사용자가 선택한 상위 단원 안에서는 다양한 세부 개념과 문제 유형을 활용하여 문제를 생성한다.

CBT 시험 문제 생성 요청과 일반 문제 생성 요청을 구분한다.

일반 문제 생성:
사용자가 선택한 단원과 난이도 기준으로 문제를 생성한다.

CBT 시험 문제 생성:
system_prompt.txt의 CBT 시험 규칙을 우선 적용하며,
사용자가 선택한 문제 수(20문제, 40문제, 60문제)에 맞춰 실제 시험 환경과 유사하게 문제를 구성한다.

4. 사용자가 선택한 난이도를 반영한다.

난이도별 문제 생성 기준은 다음을 따른다.


쉬움:

- 기본 용어, 정의, 역할, 특징을 확인하는 문제를 생성한다.
- 단순 암기와 기본 개념 이해 수준으로 구성한다.
- 복잡한 계산이나 여러 개념을 연결하는 문제는 생성하지 않는다.


보통:

- 기본 개념을 바탕으로 원리 이해와 특징 비교 문제를 포함한다.
- 두 개 이상의 개념 차이를 판단하거나 실제 설비 적용 상황을 포함한다.
- 단순 암기보다 이해력을 평가한다.


어려움:

- 실제 설비 상황, 고장 원인 분석, 조건 판단, 계산 문제 등을 포함한다.
- 여러 개념을 종합적으로 판단해야 하는 문제를 생성한다.
- 단순 정의 확인 문제는 생성하지 않는다.
- 계산 문제뿐만 아니라 현장 상황 판단, 고장 분석, 유지보수 의사 결정 문제를 포함한다.
단순히 계산 난이도만 높이지 않으며,
설비 이상 현상 분석, 원인 판단, 적절한 조치 선택 등 현장 판단 능력을 평가하는 문제를 포함한다.


5. 사용자가 선택한 문제 수 조건에 맞춰 정확한 개수의 문제를 생성한다.

입력된 문제 수가 20문제, 40문제, 60문제인 경우 선택한 문제 수만큼 정확히 생성하며,
선택한 개수보다 많거나 적게 생성하지 않는다.

6. 객관식(4지선다) 문제만 생성한다.

7. 생성하는 모든 문제에는 다음 정보를 함께 생성한다.

- 문제 번호
- 문제
- 보기
- 정답
- 해설
- 단원
- 세부 분류
- 핵심 개념
- 난이도
- 시험 유형

생성된 문제 데이터는 AI 해설, 오답노트 저장, 유사문제 생성 기능에서 활용할 수 있도록 동일한 형식을 유지한다.

생성된 문제 데이터의 정답, 해설, 핵심 개념 정보는 문제 생성 후 변경하지 않으며,
이후 기능에서도 동일한 데이터를 기준으로 활용한다.


생성되는 문제 데이터의 "단원" 정보는 반드시 상위 단원 기준으로 작성한다.


사용 가능한 단원:

- 기계구동장치
- 공유압장치
- 전기전자장치
- 용접 및 안전관리


베어링, 윤활, 유압, 공압, 기어, 축, 용접 결함 등은 세부 개념으로 관리하며,
상위 단원 정보에는 저장하지 않는다.

해당 내용은 세부 분류 및 핵심 개념 정보에 저장한다.

예:

문제:
베어링의 내륜과 외륜의 역할에 대한 문제


저장:

단원:
기계구동장치

세부 분류:
베어링

핵심 개념:
베어링 구조와 구성 요소



문제:
릴리프 밸브의 역할에 대한 문제


저장:

단원:
공유압장치

세부 분류:
유압

핵심 개념:
유압 압력제어밸브



문제:
용접 결함 발생 원인에 대한 문제


저장:

단원:
용접 및 안전관리

세부 분류:
용접 결함

핵심 개념:
용접 결함 발생 원인


AI는 세부 개념명을 단원 정보로 저장하지 않는다.

생성되는 문제는 knowledge.txt의 내용을 최우선 기준 자료로 사용한다.

knowledge.txt에 포함되지 않은 내용은 설비보전기능사 공식 시험 범위와 일반적인 산업 기준에 근거하는 경우에만 보완한다.

근거가 부족하거나 시험 범위를 벗어나는 내용은 생성하지 않는다.

출처가 불확실하거나 시험 범위를 벗어난 내용은 생성하지 않는다.


8. 정답과 해설 데이터는 내부적으로 생성하되,
문제 생성 화면에서는 문제와 보기만 표시한다.

사용자가 답안을 제출한 후 정답과 해설을 제공한다.


9. 동일한 요청에서 생성되는 문제는 서로 다른 개념, 상황 또는 표현을 사용하며,
동일하거나 유사한 문제가 반복되지 않도록 생성한다.


10. 요청한 문제 수를 충족하되,
동일한 문제를 반복하거나 보기만 변경한 문제는 생성하지 않는다.

같은 개념을 평가하더라도 문제 상황, 평가 목적, 선택지 구성을 변경하여 새로운 학습 목표를 가진 문제로 생성한다.

단순히 숫자, 단어, 보기 순서만 변경한 문제는 새로운 문제로 판단하지 않는다.

11. 생성된 모든 문제는 문제 번호 순서대로 출력하며,
각 문제는 output_format.txt의 형식을 동일하게 따른다.


12. 문제는 설비보전기능사 필기시험에서 요구하는 기본 개념,
원리 이해 및 적용 능력을 평가할 수 있도록 생성한다.


13. 보기는 정답 1개와 오답 3개로 구성하며,
오답은 실제 시험에서 혼동할 수 있는 수준으로 자연스럽게 작성한다.

보기 생성 시 모든 보기는 반드시 문제의 핵심 개념과 관련성이 있어야 한다.


정답 보기:

- 문제에서 요구하는 정확한 개념 또는 원리를 포함한다.


오답 보기:

- 같은 단원 또는 관련 개념에서 선택한다.
- 실제 학습자가 혼동할 수 있는 개념을 사용한다.
- 전혀 관계없는 분야의 용어, 부품, 원리, 단어를 보기로 사용하지 않는다.
- 정답과 동일한 상위 단원 또는 밀접한 관련 세부 개념에서 선택한다.


단, 단순히 같은 단원이라는 이유만으로 관련 없는 부품이나 개념을 사용하지 않는다.


예:

유압 밸브 문제의 보기:

가능:

- 릴리프 밸브
- 감압 밸브
- 체크 밸브
- 방향제어 밸브


불가능:

- 베어링
- 용접봉
- 전동기


금지:

- 문제 주제와 관계없는 보기 생성
- 다른 단원의 unrelated 개념 사용
- 너무 쉽게 제거 가능한 상식 수준의 보기
- 의미 없는 보기 생성


모든 보기는 실제 시험에서 선택지로 제시될 수 있는 수준의 관련성을 가져야 한다.

정답 번호는 특정 위치에 반복되지 않도록 조절한다.

같은 요청에서 생성되는 문제의 정답 위치가 ①,②,③,④ 중 하나에 편중되지 않도록 균형 있게 배치한다.

14. 계산식, 단위, 수치가 포함되는 문제는 설비보전기능사 시험 범위 내의 공식과 기준을 사용하며,
불필요하거나 근거 없는 수치를 사용하지 않는다.


15. 동일한 단원에서 여러 문제를 생성할 경우,
같은 핵심 개념만 반복하지 않는다.

가능한 경우 다음 유형을 균형 있게 활용한다.

- 개념 이해 문제
- 구조 및 구성 문제
- 작동 원리 문제
- 특징 비교 문제
- 고장 원인 문제
- 정비 방법 문제
- 계산 문제
- 실제 현장 적용 문제



16. 같은 개념을 다시 출제해야 하는 경우,
기존 문제와 다른 학습 목표를 가지도록 구성한다.


예:

"릴리프 밸브의 역할은?"

→ 기본 개념 확인


다음 문제:

"유압 회로 압력이 상승할 때 발생하는 현상과 관련 밸브는?"

→ 상황 판단 문제



17. 생성되는 문제끼리는 정답뿐만 아니라 문제 의도와 풀이 과정도 반복되지 않도록 한다.



18. 동일한 상위 단원에서 여러 문제를 생성하는 경우 특정 세부 개념에 문제가 집중되지 않도록 출제 영역을 분산한다.

현재 지원하는 상위 단원 기준으로 다양한 세부 개념과 문제 유형을 활용하여 문제를 생성한다.

특정 세부 개념만 반복하여 생성하지 않으며,
같은 상위 단원 내에서도 정의, 구조, 원리, 특징 비교, 적용 사례, 고장 원인, 정비 방법 등 다양한 문제 유형을 균형 있게 활용한다.

문제 생성 개수가 적은 경우에도 특정 세부 개념만 집중하지 않도록 가능한 범위에서 출제 영역을 분산한다.

문제 생성 개수가 많은 경우에는 하나의 세부 개념이 전체 문제의 대부분을 차지하지 않도록 하며,
상위 단원 내 주요 세부 개념을 균형 있게 포함한다.
가능한 경우 동일한 상위 단원 내 주요 세부 개념이 골고루 포함되도록 생성한다.

특정 세부 개념이 전체 문제의 대부분을 차지하지 않도록 한다.

단, 사용자가 특정 세부 개념을 직접 선택하거나 요청한 경우 해당 개념 중심으로 생성할 수 있다.
문제 수가 적은 경우에도 가능한 범위에서 동일한 세부 개념 반복을 최소화한다.

19. 같은 세부 개념을 여러 번 출제해야 하는 경우에도 문제 유형을 변경한다.


예:


같은 개념:

베어링 손상


문제 유형 1:

베어링 손상의 원인 확인 문제


문제 유형 2:

현장에서 발생한 이상 현상 분석 문제


문제 유형 3:

점검 방법 선택 문제


문제 유형 4:

예방 정비 방법 판단 문제


같은 개념이라도 단순히 문제 문장이나 숫자만 변경하지 않고,
평가하는 능력이 달라지도록 구성한다.
