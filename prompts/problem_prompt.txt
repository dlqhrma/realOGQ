# Problem Prompt

## 현재 모드
문제 생성

## 목적
사용자가 선택한 단원, 난이도, 문제 수에 맞는
설비보전기능사 필기 학습용 객관식 문제를 생성한다.

## 사용자 입력
단원 :
난이도 :
문제 수 :

## 생성 규칙

1. system_prompt.txt의 공통 규칙을 따른다.

2. 사용자가 선택한 상위 단원 범위 내에서만 문제를 생성한다.

지원 단원:
- 기계구동장치
- 공유압장치
- 전기전자장치
- 용접 및 안전관리

세부 개념은 선택된 상위 단원의
설비보전기능사 시험 범위 내에서 다양하게 활용한다.

다른 상위 단원의 핵심 개념을 문제의 주제로 사용하지 않는다.

3. knowledge.txt의 선택된 단원 내용을 최우선 기준으로 사용한다.

knowledge.txt에 없는 내용은
선택된 단원의 설비보전기능사 시험 범위에 속하고
정확한 내용인 경우에만 보완한다.

4. 사용자가 선택한 난이도를 모든 문제에 적용한다.

쉬움:
- 기본 용어, 정의, 역할, 특징 중심
- 기본 개념을 확인할 수 있는 수준

보통:
- 원리 이해, 특징 비교, 적용 상황 중심
- 유사 개념을 구분해야 하는 수준

어려움:
- 실제 설비 상황, 고장 원인 분석, 조건 판단,
  계산 또는 유지보수 판단 중심
- 여러 정보를 종합하여 판단해야 하는 수준

5. 사용자가 요청한 문제 수만큼 정확히 생성한다.

6. 동일한 요청에서는 같은 문제 또는
지나치게 유사한 문제를 반복하지 않는다.

같은 개념을 여러 번 사용해야 하는 경우
문제 상황, 평가 목적, 적용 사례 또는 판단 기준을 변경한다.

단순히 숫자, 표현, 보기 순서만 변경한 문제는 생성하지 않는다.

7. 여러 문제를 생성할 경우 가능한 범위에서
서로 다른 세부 개념과 문제 유형을 활용한다.

활용 가능한 문제 유형:
- 개념 이해
- 구조 및 구성
- 작동 원리
- 특징 비교
- 설비 적용
- 고장 원인
- 정비 및 유지보수
- 계산

8. 모든 문제는 정답 1개와 오답 3개의 4지선다로 구성한다.

오답은 문제의 핵심 개념과 관련되고
실제 학습자가 혼동할 수 있는 내용으로 작성한다.

9. 정답 번호가 ①~④ 중 특정 위치에
지나치게 집중되지 않도록 한다.

10. 각 문제의 단원 정보에는 반드시
선택된 상위 단원명을 사용한다.

세부 내용은 '세부 분류'와 '핵심 개념'에 기록한다.

예:
베어링 문제
단원: 기계구동장치
세부 분류: 베어링
핵심 개념: 해당 문제에서 평가하는 베어링 개념

11. 문제, 정답, 단원, 세부 분류,
난이도 및 핵심 개념이 서로 일치하도록 한다.

12. 일반 문제 생성에서는 문제 생성만 수행한다.
CBT 시험, AI 해설, 유사문제 생성,
개념 설명 또는 학습 분석을 수행하지 않는다.

## 출력 규칙

각 문제는 output_format.txt의
'문제 생성 출력 형식'만 사용한다.

반드시 다음 순서를 따른다.

### 문제
문제 내용

### 보기
① 보기 내용
② 보기 내용
③ 보기 내용
④ 보기 내용

### 정답
①~④ 중 실제 정답 번호

### 단원
상위 단원명

### 세부 분류
세부 분류명

### 난이도
사용자가 선택한 난이도

### 시험 유형
문제 생성

### 핵심 개념
핵심 개념

불필요한 설명이나 다른 항목은 추가하지 않는다.
