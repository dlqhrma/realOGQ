# Problem Prompt

## 현재 모드
문제 생성

## 목적
사용자가 선택한 조건에 맞는 설비보전기능사 CBT 객관식 문제를 생성한다.

## 사용자 입력

단원 :
난이도 :
문제 수 :

## 생성 규칙

사용자 입력값(단원, 난이도, 문제 수)을 기준으로 아래 규칙을 적용하여 문제를 생성한다.

1. system_prompt.txt의 모든 규칙을 따른다.
2. output_format.txt의 출력 형식을 따른다.
3. 사용자가 선택한 단원에서만 문제를 생성한다.
4. 사용자가 선택한 난이도를 반영한다.
난이도별 문제 생성 기준은 다음을 따른다.

쉬움:
- 기본 용어, 정의, 역할, 특징을 확인하는 문제를 생성한다.
- 단순 암기와 기본 개념 이해 수준으로 구성한다.
- 복잡한 계산이나 여러 개념을 연결하는 문제는 생성하지 않는다.

보통:
- 기본 개념을 바탕으로 원리 이해와 특징 비교 문제를 포함한다.
- 두 개 이상의 개념 차이를 판단하거나 실제 설비 적용 상황을 포함한다.
- 단순 암기보다 이해력을 평가한다.

어려움:
- 실제 설비 상황, 고장 원인 분석, 조건 판단, 계산 문제 등을 포함한다.
- 여러 개념을 종합적으로 판단해야 하는 문제를 생성한다.
- 단순 정의 확인 문제는 생성하지 않는다.

5. 사용자가 요청한 문제 수만큼 생성한다.
6. 객관식(4지선다) 문제만 생성한다.
7. 생성하는 모든 문제에는 다음 정보를 함께 생성한다.

- 문제
- 보기
- 정답
- 해설
- 단원
- 핵심 개념
- 난이도

생성된 문제 데이터는 AI 해설, 오답노트 저장, 유사문제 생성 기능에서 활용할 수 있도록 동일한 형식을 유지한다.
생성된 문제 데이터의 정답, 해설, 핵심 개념 정보는 문제 생성 후 변경하지 않으며, 이후 기능에서도 동일한 데이터를 기준으로 활용한다.

8. 정답과 해설 데이터는 내부적으로 생성하되, 문제 생성 화면에서는 문제와 보기만 표시한다. 사용자가 답안을 제출한 후 정답과 해설을 제공한다.
9. 동일한 요청에서 생성되는 문제는 서로 다른 개념, 상황 또는 표현을 사용하며, 동일하거나 유사한 문제가 반복되지 않도록 생성한다.
10. 요청한 문제 수를 충족하되, 동일한 문제를 반복하거나 보기만 변경한 문제는 생성하지 않는다.
11. 생성된 모든 문제는 문제 번호 순서대로 출력하며, 각 문제는 output_format.txt의 형식을 동일하게 따른다.
12. 문제는 설비보전기능사 필기시험에서 요구하는 기본 개념, 원리 이해 및 적용 능력을 평가할 수 있도록 생성한다.
13. 보기는 정답 1개와 오답 3개로 구성하며, 오답은 실제 시험에서 혼동할 수 있는 수준으로 자연스럽게 작성한다.
보기 생성 시 모든 보기는 반드시 문제의 핵심 개념과 관련성이 있어야 한다.

정답 보기:
- 문제에서 요구하는 정확한 개념 또는 원리를 포함한다.

오답 보기:
- 같은 단원 또는 관련 개념에서 선택한다.
- 실제 학습자가 혼동할 수 있는 개념을 사용한다.
- 전혀 관계없는 분야의 용어, 부품, 원리, 단어를 보기로 사용하지 않는다.

금지:
- 문제 주제와 관계없는 보기 생성
- 다른 단원의 unrelated 개념 사용
- 너무 쉽게 제거 가능한 상식 수준의 보기
- 의미 없는 보기 생성

모든 보기는 실제 시험에서 선택지로 제시될 수 있는 수준의 관련성을 가져야 한다.

14. 계산식, 단위, 수치가 포함되는 문제는 설비보전기능사 시험 범위 내의 공식과 기준을 사용하며, 불필요하거나 근거 없는 수치를 사용하지 않는다.
15. 동일한 단원에서 여러 문제를 생성할 경우,
같은 핵심 개념만 반복하지 않는다.

가능한 경우 다음 유형을 균형 있게 활용한다.

- 개념 이해 문제
- 구조 및 구성 문제
- 작동 원리 문제
- 특징 비교 문제
- 고장 원인 문제
- 정비 방법 문제
- 계산 문제
- 실제 현장 적용 문제


16. 같은 개념을 다시 출제해야 하는 경우,
기존 문제와 다른 학습 목표를 가지도록 구성한다.

예:
"릴리프 밸브의 역할은?"
→ 기본 개념 확인

다음 문제:
"유압 회로 압력이 상승할 때 발생하는 현상과 관련 밸브는?"
→ 상황 판단 문제

17. 생성되는 문제끼리는 정답뿐만 아니라 문제 의도와 풀이 과정도 반복되지 않도록 한다.

18. 동일한 단원에서 여러 문제를 생성하는 경우 특정 세부 개념에 문제가 집중되지 않도록 출제 영역을 분산한다.

같은 단원이라도 다양한 세부 개념을 활용하여 문제를 생성한다.

예:

베어링 단원:
- 베어링의 종류와 특징
- 베어링 구조와 구성 요소
- 베어링 설치 방법
- 베어링 손상 원인
- 베어링 점검 및 유지보수 방법
- 베어링 윤활 관리

용접 단원:
- 용접 원리
- 용접 종류
- 용접 결함
- 용접 작업 조건
- 용접 안전 관리

윤활 단원:
- 윤활 목적
- 윤활제 종류
- 점도와 윤활 조건
- 윤활 방법
- 윤활 이상 원인

유압 단원:
- 유압 기본 원리
- 유압 장치 구성 요소
- 유압 밸브 역할
- 유압 회로 작동 원리
- 유압 고장 원인

공압 단원:
- 공압 기본 원리
- 공압 기기 종류
- 방향 제어 밸브
- 공압 회로
- 공압 고장 원인

기계요소 단원:
- 축과 축이음
- 기어
- 벨트와 체인
- 나사
- 키와 핀
- 스프링

특정 세부 개념만 반복하여 생성하지 않으며,
같은 단원 내에서도 정의, 구조, 원리, 특징 비교, 적용 사례, 고장 원인, 정비 방법 등 다양한 문제 유형을 균형 있게 활용한다.

19. 같은 세부 개념을 여러 번 출제해야 하는 경우에도 문제 유형을 변경한다.

예:

같은 개념:
베어링 손상

문제 유형 1:
베어링 손상의 원인 확인 문제

문제 유형 2:
현장에서 발생한 이상 현상 분석 문제

문제 유형 3:
점검 방법 선택 문제

문제 유형 4:
예방 정비 방법 판단 문제

같은 개념이라도 단순히 문제 문장이나 숫자만 변경하지 않고,
평가하는 능력이 달라지도록 구성한다.
