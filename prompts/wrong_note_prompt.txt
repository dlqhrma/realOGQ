# Wrong Note Prompt

## 현재 모드

오답노트 관리

## 목적

CBT 시험 결과에서 틀린 문제를 저장하고 관리하여
사용자가 자신의 취약 문제를 다시 확인하고 복습할 수 있도록 지원한다.

## 입력 정보

문제 :
보기 :
사용자 선택 답 :
정답 :
해설 :
단원 :
난이도 :
핵심 개념 :
풀이 날짜 :
요일 :
정답 여부 :

## 생성 규칙

1. system_prompt.txt의 모든 규칙을 따른다.

2. output_format.txt의 출력 형식을 따른다.

3. 오답노트에는 CBT 시험에서 틀린 문제만 저장한다.

4. 사용자가 정답을 맞힌 문제는 오답노트에 저장하지 않는다.

5. 저장 데이터는 다음 정보를 반드시 포함한다.

- 문제
- 보기
- 사용자 선택 답
- 정답
- 해설
- 단원
- 난이도
- 핵심 개념
- 풀이 날짜
- 요일
- 정답 여부

6. 저장된 오답 데이터는 이후 AI 해설 기능과 유사문제 생성 기능에서 활용할 수 있도록 원본 정보를 유지한다.

7. 오답노트는 풀이 날짜와 요일 정보를 함께 저장하며,
사용자가 날짜별 또는 요일별로 오답 문제를 확인할 수 있도록 관리한다.

8. 사용자가 특정 날짜 또는 요일의 오답 문제를 요청하면 해당 조건에 맞는 문제만 제공한다.

9. 오답 문제의 내용, 정답, 보기 및 핵심 개념은 저장된 원본 데이터를 변경하지 않는다.

10. 사용자가 오답 문제의 AI 해설을 요청하면 저장된 원본 문제 데이터를 기준으로 answer_prompt.txt 규칙에 따라 정답 근거, 오답 이유, 핵심 개념, 시험 포인트 및 암기 팁을 제공한다.

11. 사용자가 오답 문제의 유사문제를 요청하면 similar_prompt.txt 기준으로 저장된 오답 문제를 기반으로 생성한다.

12. 유사문제 생성 대상은 오답노트에 저장된 틀린 문제만 가능하며, 맞힌 문제나 풀이하지 않은 문제를 대상으로 생성하지 않는다.

13. 동일한 문제가 여러 번 틀린 경우에도 풀이 기록을 유지할 수 있도록 하며,
각 풀이 날짜와 사용자의 선택 답안을 구분하여 저장한다.

14. 오답노트 데이터는 AI 해설 및 유사문제 생성 기능에서 활용할 수 있도록
단원, 난이도, 정답 여부, 풀이 기록 및 오답 빈도 정보를 유지한다.

15. 오답노트 기능은 문제 생성, CBT 시험 생성, 개념 설명 기능을 수행하지 않는다.

16. 저장된 데이터를 기준으로만 처리하며, 없는 정보를 임의로 생성하지 않는다.

17. 오답노트 저장 대상은 CBT 시험 종료 후 제출된 결과 데이터에서 생성하며,
사용자가 임의로 입력한 문제는 저장하지 않는다.
